# Simple Music Player

Simple Music Player，简称 SMP，是一款使用 Kotlin 开发的 Android 音乐播放器，面向本地音乐管理、歌单管理、播放控制和轻量流媒体播放场景。

当前支持自动扫描 Android 系统媒体库、手动导入音频/CUE/LRC 文件、授权文件夹扫描、读取标题、歌手、专辑、年份、时长、曲序、作曲家、时间戳和封面等音乐元数据。播放界面支持歌词按时间显示、封面手势切歌、正在播放队列、播放模式、倍速、音量和歌曲详细信息。

歌单方面，SMP 支持普通歌单、我喜欢的音乐、最近播放、播放排行、CUE 歌单和自动专辑歌单。用户可以为音乐添加别名、点评、标签和星级评分，并在音乐库中搜索或筛选。

外观方面，SMP 使用 Material Design 3 的组件与颜色角色，支持主题色、背景图片、浅色模式、深色模式和跟随系统。自定义 RGB 作为主题种子生成可读的配色，背景图保持透明度设置并叠加可读性遮罩。悬浮歌词可以设置显示位置、透明度，并使用主题色显示描边文本。

在线音乐页顶部可以切换 Dizzylab 与 Subsonic。Dizzylab 支持发现、搜索、已购、喜欢、社团、专辑详情、播放和授权单曲下载；Subsonic/Navidrome 兼容服务器保留搜索、艺术家/专辑/歌单浏览、随机音乐、播放与下载。WebDAV 仍可从流媒体模式进入。

Dizzylab 账户页位于设置的流媒体账号凭证中，包含账户、关注动态、关注社团、CDK 兑换和网页消息等入口。付费购买在网站 WebView 中完成，免费专辑领取与 CDK 兑换支持原生操作。下载继续使用播放器的队列和目录设置，网站提供的整包 ZIP 可保存但暂不自动解压。

本项目使用 ChatGPT 辅助构建。音乐格式转换功能中的 NCM 解密核心参考并移植自 MIT 许可项目 NCMConverter4a。
