# Dizzylab 客户端实施记录

实施与验证日期：2026-10-28。预发行版本：`2.1.0-beta.1`（versionCode 29）。初始端点调查见 [README.md](README.md)；本文记录当前代码的实际覆盖范围，不把调查中发现的全部端点视为已实现功能。

## 当前界面与能力

- 底部「在线音乐」统一承载音乐来源，顶部下拉选择 Subsonic 或 Dizzylab。来源使用稳定键保存，通过 `OnlineMusicSource` 枚举集中声明，后续来源需要补充对应页面与协议适配。
- Subsonic 原有搜索、艺术家、歌曲、专辑、歌单、随机音乐和播放下载入口保留。原「流媒体模式」仅保留 WebDAV；Dizzylab 音乐入口迁入在线音乐页。
- Dizzylab 支持原生发现、全站搜索、已购、喜欢、社团与社团作品、网络分页、专辑详情、队列播放、远端专辑喜欢，以及授权单曲 MP3 128/320 下载。
- 设置 → 用户账号 → 流媒体账号凭证 → Dizzylab 打开独立账户页：资料验证、原生关注动态与关注社团、CDK 兑换、下载音质、登录及退出。账户资料修改、收件箱和订单使用站内 WebView。
- 免费专辑原生领取前重新确认价格、上架及预售状态，已拥有时不重复提交。付费专辑只打开 WebView；没有原生付费订单创建、结算或支付 SDK。
- CDK 先预检，用户确认后才调用兑换确认接口；需要网页处理的类型保留网页入口。真实兑换码未在本次测试中消耗。
- WebView 整包下载交给播放器现有下载队列，支持流式保存网站提供的 ZIP。ZIP 暂不自动解压或把其中曲目导入音乐库。

## 与原播放器的连接

复用 `Track`、播放器、混合播放队列、系统媒体控制、曲目菜单、下载任务队列、移动网络提示、下载目录选择、标签写入及本地库导入。没有建立另一套播放器或下载管理器。单曲下载使用授权下载接口，与试听 URL 分开；播放前通过专辑和曲目 ID 重新解析媒体地址。

Dizzylab 请求保留在 `DizzylabApiClient` / `DizzylabClient`，来源状态由在线音乐页调度。曲目身份采用 `stream:dizzylab:<discid>:<trackid>`，避免把临时签名 URL 当作长期身份。来源扩展仍需实现具体协议，不是加载插件即可自动适配任意服务。

共享下载写入处理临时文件和失败清理；失败任务不再被后续完成逻辑误标为成功。WebDAV 请求依据文件所属服务器取得凭据，Dizzylab 的 Cookie 不进入媒体 CDN 或其他来源请求。

## 会话处理

网页登录在站内 WebView 完成，通过已登录个人页面取得 API Token，并以用户资料接口校验身份。Cookie 与 Token 用途分离；JSON API 不附带网页 Cookie。会话使用 Android Keystore AES/GCM 加密保存，排除系统备份和配置导出；不保存账号密码。旧配置 Cookie 可迁移到独立会话存储。

只允许受信 Dizzylab 站点参与会话桥接，媒体地址限制到已调查的 HTTPS 主机。HTTP 200 的 HTML 错误不会被当成 JSON 或音频；写请求关闭自动重试，连接丢失时提示先刷新状态。退出仅清理 Dizzylab 会话，保留其他来源及本地文件。

## 工具链与验证

使用 `D:\Android\Android Studio\jbr` 和 `D:\Android\SDK`，AGP 9.1.1、Gradle Wrapper 9.3.1、compileSdk 36、Java/Kotlin 字节码 17。保留 targetSdk 35 与 minSdk 26。调试包使用 `com.supermite.smp.debug`，避免覆盖正式应用。

在项目根目录执行：

```powershell
.\tools\android.ps1 -Task Check -UseSystemProxy
.\tools\android.ps1 -Task Emulator
.\tools\android.ps1 -Task Install -UseSystemProxy
```

`Check` 包含调试 APK、单元测试和 Android Lint；`UseSystemProxy` 仅在本机 Java 依赖下载需要系统代理时使用。APK 输出为 `app/build/outputs/apk/debug/app-debug.apk`。

自动契约测试覆盖 17 项场景：参数编码、分页、Token/Cookie 隔离、HTTP 200 HTML、错误数据结构、稳定 ID、跨域重定向拦截、免费领取边界、CDK 预检/确认、写请求不重试、关注动态数据结构及媒体地址限制。测试使用本地 MockWebServer 和合成数据，不包含真实凭证。

最终检查结果：调试构建成功，17 项契约测试全部通过，Lint 为 0 个错误、118 个现有警告。文档相对链接和 JSON 可解析检查通过。

模拟器使用 `D:\Android\AVD` 的 Medium_Phone。已实测来源切换、游客列表与详情、真实媒体播放/暂停、付费专辑 WebView 入口、网页登录与重新启动后的会话恢复、原生账户资料、关注动态及关注社团。CDK 空输入停留在输入界面，不进入兑换确认。已购单曲下载得到约 14.3 MB 的本地 MP3，自动加入原有本地音乐库，并由同一播放器成功播放。大字体下检查了音乐列表、详情和来源菜单。没有执行真实付费购买、免费领取或有效 CDK 兑换，也没有发送消息或修改账户资料。

测试结束后清除了隔离调试包的数据，核验会话偏好、WebView 数据和测试下载均已移除，并恢复模拟器原有字体设置。正式应用未覆盖，测试账号与密码未写入项目。

## 保留的边界

- Subsonic 与 WebDAV 保留原协议实现和页面；本轮未取得这些服务器的真实凭据，不能视为已完成真实服务器全量回归。
- 关注、喜欢、领取、兑换等真实写入的所有服务端错误类型仍需逐项补充验收。消息与账号修改由网站处理。
- 原生页面尚未覆盖评论/REPO、排行榜、随机听、商品特典模型、运营后台和游戏；这不是初始 P0–P3 全部路线的完成声明。
- Token 与签名 URL 的真实有效期没有测定；服务器协议或页面结构变化可能需要更新桥接解析。
- 现有项目的 Lint 警告仍保留；本次修复阻止构建的错误，没有为消除所有历史警告改写无关功能。
