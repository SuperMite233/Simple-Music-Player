# 缓存、运行日志与歌曲记录

## 存储边界

所有可重建磁盘缓存统一位于应用 `noBackupFilesDir/managed-cache/`。用户指定的下载目录、最终转换音乐、配置、账号凭证和有用户行为的播放记录不在这个根目录中，不由缓存清理器删除。

| 分类 | 子目录 | 默认上限 | 内容 |
|---|---|---:|---|
| 串流音频 | audio | 1536 MiB | 按服务器、曲目、转码模式区分的音频 |
| 封面图片 | artwork | 192 MiB | 内容 SHA-256 去重的图片和 URL 别名、本地派生封面 |
| 在线歌曲信息 | metadata | 96 MiB | 未形成长期用户记录的可重建歌曲快照 |
| 目录索引 | index | 32 MiB | WebDAV 目录结果与有效期 |
| 运行日志 | logs | 32 MiB | 经过脱敏的轮转运行日志 |
| 临时文件 | temporary | 64 MiB | 转换、元数据写入和本次播放暂存 |

总上限默认 2048 MiB，初次迁移可读取旧缓存上限。每一类都有独立开关、上限和清理操作，同时服从总上限。分类之和可以大于总上限，空间不足按最近访问时间回收。已租用的播放/任务文件受保护；缩小上限或清理时，正在使用的文件在任务结束后回收。

关闭持久音频缓存后，若临时空间允许，可使用一次性暂存，换曲/退出后删除。关闭临时文件或配额不足时，不偷偷写到其他目录绕过设置；可直连的播放走直连，需要暂存的操作给出明确提示。下载完成的音乐是用户文件，不会因关闭音频缓存被删除。

旧 `StreamCache`、派生封面和 `stream_metadata` 在后台按已知应用自有路径迁移；旧日志导入前脱敏。迁移不会移动下载音乐。旧“缓存位置”曾与实际路径不一致，现移除该假选择入口：缓存根目录由应用统一管理，下载/输出目录仍独立选择。旧持久封面路径继续通过兼容解析找到迁移后的文件。

## 图片和歌曲信息

封面先同步检查持久缓存命中，相同图片不重新显示占位并再次请求。并发相同 URL 采用单飞请求；Subsonic 请求中的随机认证参数不参与图片身份，但服务器、用户、图片 ID 和尺寸仍隔离；不同 URL 的相同图片字节共享内容 blob。

长期曲目记录与临时元数据分离。规范化歌名与有效歌手相同可合并；缺少歌手时才谨慎采用专辑辅助匹配，同名不同歌手不合并。保留各来源稳定 ID 与来源引用，合并历史、播放次数、评分、标签、收藏，播放时重新取得需要认证/短时效的资源地址。未播放、未编辑、未收藏等浏览快照受 METADATA 配额限制；产生用户行为的来源快照和别名进入长期音乐库，不随缓存清理消失。

## 日志设置

调试升级为“运行日志与诊断”，默认启用、最低等级 VERBOSE、最长保留 7 天。可选择 VERBOSE/DEBUG/INFO/WARN/ERROR 和 1–365 天，预览脱敏文本、按文件多选导出 ZIP。

从 Application 启动记录进程、Activity 生命周期、导航、状态、同 UID logcat 和未捕获异常。无需读取其他应用日志权限，不读取整个设备日志。记录器进程内单例，开关不会启动多份采集进程。

日志按约 512 KiB 轮转，持续服从 LOGS 分类和总缓存上限。保留天数是时间上限，空间不足会提前删除旧文件，不能承诺空间耗尽时仍保存完整一周。关闭 LOGS 分类会停止记录。预览有字符上限；导出直接流式写入用户选定的 ZIP，不在私有缓存中生成无限副本。

写盘、导入旧日志、预览和导出均脱敏 Cookie、Authorization、密码、Token、认证查询参数、JWT、URL 用户信息和邮箱。原来 WebDAV 测试中拼接明文密码的调用已移除。分享日志仍应先预览确认。

## NCM 输出

NCM 转换核心、目录选择和应用入库继续复用。内部暂存改用受 TEMP 配额限制的工作文件；文件名和头部校验、解密和元数据写入成功后，默认将音频发布到系统 `Music/SMP/ConvertedMusic` 并提交 MediaStore。选择下载目录时提交最终落盘 URI 的媒体更新；选择可写原目录时扫描实际最终文件。

系统文件管理器通过 VIEW/SEND 与 .ncm/专属 MIME 关联进入确认流程；客户端只转换用户明确选择的文件。Android 是否显示此应用为候选取决于文件管理器提供的 MIME 和 URI。无法确认某个非主存储卷/文件提供方是否被系统收录时，会显示实际扫描状态，不把 notifyChange 当作已成功入库。

默认输出已注册到系统媒体库；用户选择 SOURCE 而无可写公开路径时回退到系统音乐目录。API 26–28 请求发布音乐所需的写入权限。最终音乐不计入临时缓存，失败的暂存会清理。
