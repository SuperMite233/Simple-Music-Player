# beta-2.0.0-20261030

本次统一 Material Design 3 界面并整理存储、诊断、播放与更新行为。

- 设置按用途分组，统一开关、下拉、输入、滑条和图标；保留主题色、深色/跟随系统与背景图设置。
- 六类缓存独立开关、限额、清理，统一实际存储根目录并共同受总配额约束；下载音乐和长期播放记录独立保留。
- 运行日志默认开启、保留上限七天，支持等级、时长、预览、选择文件导出与敏感信息脱敏；受缓存配额限制。
- 流媒体封面持久化与相同内容去重；按规范化歌名、歌手/专辑谨慎合并多来源播放记录，保留可播放来源。
- NCM 转换后发布/扫描系统媒体库，支持文件管理器打开和分享 NCM 进入确认转换。
- 来源选择增加容器和大箭头，Dizzylab 功能图标区分；追加列表和详情返回保留位置。
- 迷你播放器去框，改进进度与播放控件；长标题单行滚动并保留点击、滑动手势。
- 更新按 GitHub 发布日期与正式/预发行频道筛选；版本、包名和长期签名规则文档化。

Dizzylab 付费购买仍在网页中完成，复用现有播放/下载功能；本次不增加原生付费下单。
