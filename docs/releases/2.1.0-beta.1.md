# SMP 2.1.0-beta.1

本次预发行将 Dizzylab 接入统一在线音乐界面，保留 Subsonic/Navidrome、WebDAV 与本地播放器功能。

## 更新内容

- 在线音乐顶部下拉切换 Subsonic / Dizzylab，预留后续音乐来源的扩展位置；旧流媒体模式保留 WebDAV。
- Dizzylab 原生发现、搜索、已购、喜欢、社团作品、专辑详情与分页浏览，复用现有播放器、队列及系统媒体控制。
- 独立 Dizzylab 账户页提供资料验证、关注动态、关注社团、下载音质、登录与退出；账户设置、消息及订单在站内 WebView 中处理。
- 原生免费专辑领取与 CDK 预检/确认。付费购买仅引导到 WebView，不接入原生付费订单或支付 SDK。
- 授权 MP3 128/320 下载复用原下载队列、目录选择、标签写入及本地库导入；网站 ZIP 整包进入同一队列，暂不自动解压。
- Cookie/Token 独立加密保存，排除系统备份及配置导出；媒体与其他来源请求不携带 Dizzylab Cookie。
- 迁移至 D:\Android 下的 Android Studio 工具链，加入 Gradle Wrapper、构建脚本与接口契约测试。

## 安装与源码

- `SMP-2.1.0-beta.1-debug.apk`：Android 8.0 及以上，versionCode 29。调试包应用 ID 为 `com.supermite.smp.debug`，可与正式版并存，数据独立；不会直接覆盖正式版。
- `SMP-2.1.0-beta.1-source.zip`：与本次发布提交对应的源码，不含构建缓存、测试会话或凭证。
- `SHA256SUMS.txt`：APK 与源码 ZIP 的 SHA-256 校验值。

## 验证与范围

调试构建、17 项契约测试和 Android Lint 通过，Lint 无错误，保留 118 项历史警告。模拟器已验证来源切换、游客播放与暂停、网页登录及会话恢复、账户和关注列表、单曲下载自动入库及本地播放。测试登录数据已清理。

未实际执行付费购买、免费领取或有效 CDK 兑换，也未发送消息或修改账户资料。Subsonic/WebDAV 本轮未使用真实服务器完成全量回归。评论/REPO、排行榜、随机听、运营后台等尚未原生化。

完整接口调查和实施边界见 [实施与验证记录](https://github.com/SuperMite233/Simple-Music-Player/blob/v2.1.0-beta.1/docs/dizzylab-investigation/implementation-status.md)。
